
# 💰 Finance Tracker

A simple Finance Tracker desktop app developed using **Java (with NetBeans)** and a touch of **HTML** for UI components. It allows users to track expenses, manage categories, and view financial reports in a user-friendly way.

---

## 📌 Features

- User registration & login system
- Add, edit, and delete transactions
- Categorize expenses (e.g., Food, Transport, Bills)
- View income vs expenses in a table or graph
- Basic HTML used for rendering UI inside NetBeans (e.g., `JEditorPane`)
- Connected to a MySQL database for data persistence
